ポータブルコーン貫入試験 PWA v1.0.6

【v1.0.6 追加・変更】
・測定深度を 0.0～2.0m に拡張（0.1mピッチ、21点）
・入力画面、アプリ内グラフ、PDF・印刷、Excel帳票を2.0mまで対応
・Excelグラフは qc × 深さ の1系列、非表示補助列 S/T を使用
・Excelの深度行は A10:A30、グラフ参照は S10:S30 / T10:T30
・最終貫入深さは、最後にダイヤル値を入力した深さを自動表示
・v1.0.5以前の1.0mデータをそのまま読み込み、1.1～2.0mだけ空欄追加
・旧データの原文を cone_pwa_depth2_backup_v1 に退避してから2.0m表示へ補完
・既存の保存キー cone_pwa_draft_v1 / cone_pwa_saved_v1 は変更なし
・保存済みデータは最大100件のまま
・起動時に version.json を自動確認し、新版があれば画面上部へ更新通知
・アプリをバックグラウンドから戻した時にも更新確認
・オンライン中は1時間ごとにも最新版を確認
・更新時は入力途中／保存済みデータを cone_pwa_update_backup_v1 に退避してからアプリ本体のみ更新

・保存済みデータが0件でバックアップにデータが残る場合、起動時に復元案内を表示
・「保存データ」画面からもバックアップ復元を実行可能
・復元直前の状態を cone_pwa_pre_restore_backup_v1 に退避してから復元
・「PC用データ出力」→「バックアップ出力」、「データ読込」→「バックアップ読込」に名称整理
・バックアップ出力は「入力途中データ＋端末保存データ全件」を1つのJSONへ一括保存
・バックアップ読込は全件復元に対応し、復元直前の端末状態を別領域へ退避
・v1.0.5以前の旧「1測点JSON」も互換読込可能

【データ保護】
・localStorage.clear() は使用しません。
・v1.0.5以前の保存データを削除・初期化しません。
・旧保存データは、開いた時だけ2.0m形式へ補完し、明示的に保存するまでは元の保存データを上書きしません。
・深度2.0m移行前バックアップ：cone_pwa_depth2_backup_v1
・更新前バックアップ：cone_pwa_update_backup_v1
・バックアップ復元直前の保全：cone_pwa_pre_restore_backup_v1
