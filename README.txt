ポータブルコーン貫入試験 PWA v1.0.2

【できること】
・スマホで深さ／ロッド本数／ダイヤル読みを入力
・Qrd、qcをExcelと同じ式で自動計算
・横軸qc、縦軸深さ（下ほど深い）のグラフを自動描画
・端末内保存、保存履歴
・PC受け渡し用JSON出力／読込
・CSV出力
・大元Excel様式に合わせたA4縦のPDF／紙印刷
・一度読み込んだ後はオフライン使用可能

【初期設定】
K = 4.4 N/目盛
m1 = 0.78 kg
m0 = 0.135 kg
A = 0.000645 m2
校正範囲 = ダイヤル読み 0〜232.1

【公開方法（無料）】
1. このフォルダ一式をGitHubリポジトリへ置く
2. Cloudflare Pages等の静的ホスティングに接続
3. 発行されたhttps://〜のURLをスマホで開く
4. iPhone: Safariの共有 → ホーム画面に追加
   Android/Chrome: メニュー → アプリをインストール / ホーム画面に追加

※PWAのインストールにはHTTPS配信が必要です。file://で直接開いただけではインストールできません。
