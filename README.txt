ポータブルコーン貫入試験 PWA v1.0.5

【v1.0.5 確定修正】
・Excel帳票のグラフを qc × 深さ の1系列に固定
・グラフは非表示補助列 S/T を参照
  S列：ダイヤル入力あり → qc、未測定 → #N/A
  T列：ダイヤル入力あり → 深さ、未測定 → #N/A
  これにより未測定行が qc=0 として描画される現象を防止
・Excel出力時のグラフ数値キャッシュも現在の測定値へ同期
・Excelでダイヤル値を修正した場合も、qc再計算 → 補助列再計算 → グラフ更新の順で連動
・不要な第2系列は使用しない
・列幅、行高さ、フォントサイズ、余白、印刷範囲はA4 PDF帳票と整合する設定を維持
・記事欄はExcelの縮小表示に合わせ、PDF・印刷でも1行内に自動縮小してはみ出さないよう修正
・ダイヤル入力欄のみ薄青、Qrd/qcは白背景
・A4縦1ページ、印刷範囲 A1:R54 を固定
・記事欄、Excel帳票、空白Excel、最新版確認、保存して次の測定などv1.0.4までの機能は継続
・既存保存キー／保存データ形式／最大100件保存は変更なし
