ポータブルコーン貫入試験 PWA v1.0.4

【v1.0.4 追加・変更】
・各測定深さに「記事」入力欄を追加
  例：転石に当たり貫入不可、礫に当たり再測定 など
・記事は端末内自動保存、保存データ、JSONバックアップ、PDF印刷、Excel帳票に引き継ぐ
・校正範囲外の警告と現場記事が両方ある場合は、記事欄に併記
・CSV出力を画面から廃止
・「Excel帳票」出力を追加
  現在の入力内容を、従来のポータブルコーン貫入試験Excel帳票様式で .xlsx 出力
・「空白Excel様式」出力を追加
  データ未入力の標準Excel帳票を .xlsx で出力
・アプリ起動時に最新版を確認
  新版がある場合は画面上に更新案内を表示し、利用者が「最新版へ更新」を押して更新
・更新前に入力途中データと保存データの安全バックアップを端末内に作成
・Service Workerの更新方式を見直し、オンライン時は新しい本体ファイルを優先取得
・既存の保存キー、保存データ形式、最大100件保存は継続
・v1.0.3以前の保存データをそのまま読み込み可能

【既存機能】
・スマホで深さ／ロッド本数／ダイヤル読みを入力
・Qrd、qcを自動計算
・深さ－qcグラフを自動描画
・入力途中の端末内自動保存
・「端末に保存」および保存データ一覧
・「保存して次の測定」
  現在測点を保存後、調査件名・地盤高・測定者・測定日・天候・機器設定を引き継ぎ、地点番号と測定値だけ初期化
・PC受け渡し用JSON出力／読込
・A4帳票PDF／紙印刷
・オフライン使用

【更新時のデータ保護】
アプリ本体の更新対象はHTML／JavaScript／CSS／Service Worker等のキャッシュです。
測定データはlocalStorageに保存されており、更新処理では削除しません。
保存キー：
  cone_pwa_draft_v1
  cone_pwa_saved_v1
更新前バックアップ：
  cone_pwa_update_backup_v1
