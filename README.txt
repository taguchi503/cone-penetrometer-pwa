ポータブルコーン貫入試験 PWA v1.0.3


【v1.0.3 追加機能】
・「保存して次の測定」ボタンを追加
・現在の測定を1件として保存した後、新しい測定IDへ切替
・調査件名／地盤高／測定者／測定日／天候／試験機設定は引継ぎ
・地点番号だけ空欄にし、測定値とグラフを初期化
・連続測定時に工事情報を再入力せず、次の測点へ移行可能
・既存の「新規」ボタンは従来どおり全項目を初期化

【できること】
・スマホで深さ／ロッド本数／ダイヤル読みを入力
・Qrd、qcをExcelと同じ式で自動計算
・横軸qc、縦軸深さ（下ほど深い）のグラフを自動描画
・端末内保存、保存履歴
・PC受け渡し用JSON出力／読込
・CSV出力
・大元Excel様式に合わせたA4縦のPDF／紙印刷
・一度読み込んだ後はオフライン使用可能

【初期設定】
K = 4.4 N/目盛
m1 = 0.78 kg
m0 = 0.135 kg
A = 0.000645 m2
校正範囲 = ダイヤル読み 0〜232.1

【公開方法（無料）】
1. このフォルダ一式をGitHubリポジトリへ置く
2. Cloudflare Pages等の静的ホスティングに接続
3. 発行されたhttps://〜のURLをスマホで開く
4. iPhone: Safariの共有 → ホーム画面に追加
   Android/Chrome: メニュー → アプリをインストール / ホーム画面に追加

※PWAのインストールにはHTTPS配信が必要です。file://で直接開いただけではインストールできません。
